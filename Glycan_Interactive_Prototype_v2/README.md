# Glycan Flow Simulator — ライトテーマ・デスクトップ1画面版 v6

GitHub上での保存先は、**既存の `Glycan_Interactive_Prototype_v2` フォルダ**です。バージョンが上がってもフォルダ名を増やさず、同じ場所のファイルを更新するため、ZIP内もこの名前にしています。

## 使い方

1. ZIPを解凍して `Glycan_Interactive_Prototype_v2/index.html` をダブルクリックしてください（完全オフライン対応）。
2. 最初に黄色い **E13** が選ばれています。スライダーを100%から150%へ動かしてみてください。
3. 目標との差が **31.9 → 26.9 pt** と小さくなり、「4.9ポイント近づきました」と表示されます（丸めにより小数が変わることがあります）。
4. **UQ / CWQ / SU / LCRQ** を押すと、容量設定を保ったまま配分が変わります。
5. 「Inverseで容量を逆算してみる」から、固定目標を再現する容量補正の例を表示します。

## v3からv4で変更した点

- 黄色の線 **E13** を初期選択し、最初に行う具体的な操作を提示。実際に目標のズレが減る条件を計算で確認済み。
- スライダー変更・4手法の切り替えごとに「近づいた／遠ざかった／ほぼ変わらない」を、操作前後の目標との差で表示。
- 最初は容量操作に集中できるよう、計算方法の説明を段階的に変更。選んだ手法の短い説明は常に表示。
- Inverseのボタン前に「手動は難しいから自動が優れている」ではなく「目標分布から容量を逆算する」という案内を追加。ただし **Inverseは手動容量から直接補正していない** ことを同じ画面に明記。
- ライトテーマ、ネットワークのアニメーション、Forward/Inverse数値計算、3系列比較はそのまま。

## 科学的な扱い

- この例は **架空の小規模ネットワークと容量** を使用しています。RNA/TPMデータや測定した糖鎖分布ではありません。
- 目標は固定された説明用の **A=25%, B=20%, C=55%**。表示上のズレは `0.5 × Σ |予測割合 − 目標割合|`（パーセンテージポイント）。総生成量が0の場合はズレを定義せず `—` と表示します。
- Forwardは最大流量を求めて固定し、選択した二次目的関数で配分します。**目標との差の最小化をForwardが自動で行うわけではありません。**
- Inverseは基準容量から容量変更量を最小にして目標分布を再現する、事前計算した検証用フィクスチャです。**今の手動設定を入力とした補正ではありません。**
- Inverse後の流量解が、同じ補正容量に対するUQ/CWQ/SU/LCRQの流量解と一致するとは限りません。

## v6: Forwardを一画面で操作できるように変更

- デスクトップ（横幅1100px以上・縦700px以上）で、Forwardのネットワーク図、エッジ容量スライダー、4手法ボタン、生成割合グラフ、Inverseへのボタンを同時に表示できるコンパクトレイアウトにしました。1280×720 / 1366×768 / 1829×864 / 1920×1080 の画面で縦スクロール不要を検証しています。ブラウザの拡大率、OS表示倍率等により、実際にはスクロールが必要になる場合があります。
- 反応ネットワークの表示座標を縦方向に少し圧縮し、限られた高さでも線・ノードが読み取りやすいサイズを確保しました。**数理モデル、計算値、反応容量は変更していません。**
- 4手法の初期容量比較は、ボタンの直下に重ねて表示する方式にしました。比較後はボタンで閉じられ、元の容量設定も残ります。
- 小さい画面・スマホでは文字やグラフを無理に縮めず、従来どおり縦スクロールして利用できます。Inverse側も無理に一画面へ押し込んでいません。
- 画面全体を短くするため、目標との差の数値をまとめ、細かい研究説明は「このアプリと研究の関係」に格納しました。

## 今回の文章調整

- Forwardは「容量から生成割合を予測する」、Inverseは「目標分布を説明する容量の補正を求める」という違いが伝わるように、Inverseへの案内と説明文を変更しました。
- 自分で操作する楽しさと目標との差の表示は残していますが、研究として自動補正が手動操作より「優秀」だとは説明していません。
- 計算コードや容量値・固定目標・可視化の動作は変更していません。


## v5: シンプルな比較機能と容量ラベル

- 反応容量のスライダーは **0%（停止） / 100%（初期の基準容量） / 200%（基準容量の2倍）** を目盛りとして明示しています。これは生物学的に測定した酵素活性の倍率ではなく、仮想的なWhat-if操作です。
- 「4手法を同じ初期容量で比較する」を押すと、**全エッジを100%にした同じ容量条件**で UQ / CWQ / SU / LCRQ の実際の Forward 計算結果を表示します。
- 比較は4手法の予測の違いを示すもので、人工的な目標にどれが最も近いかによって手法の優劣を示すものではありません。
- 手動で変更した容量や選択中の手法は、比較を開いたり閉じたりしても保持します。各手法ボタンは従来どおり、現在の手動容量条件で計算します。
- Inverseはこれまでどおり別モードで、固定目標と元の基準容量から得られた説明用の補正結果を表示します。
